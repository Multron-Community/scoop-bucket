# Multron Scoop Bucket

Official [Scoop](https://scoop.sh) bucket for **Multron Download Manager** and related Multron applications.

## Installation

1. Add the Multron bucket to Scoop:

```powershell
scoop bucket add multron https://github.com/Multron-Community/scoop-bucket
```

2. Install **Multron Download Manager**:

```powershell
scoop install multron/multron-download-manager
```

## Updating

```powershell
scoop update multron-download-manager
```

## Uninstalling

```powershell
scoop uninstall multron-download-manager
```
